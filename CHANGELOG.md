# Changelog

## Unreleased

### Added

- `Dialog` component built on Base UI Dialog, with sizes, header, footer and scroll dividers.
- `AlertDialog` component, composed from `Dialog` with `role="alertdialog"`, no close button and no outside-click dismissal, in `extraSmall` and `small` sizes.
- `Dialog` accepts `popupProps` to pass extra props, such as `role`, to its popup element.
- Tokens for `padding` (`lg`, `xl`), `gap` (`sm`, `md`), `cornerRadius.lg`, `heading.md`, `body.md` and `shadow.24`, and `shadow` type support in the token build script.
